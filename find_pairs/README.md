# Royal Purple — Найди пару или тройку

Мини-игра на Python и Pygame в фиолетово-золотом стиле.

## Возможности

- Режим «Найди пару».
- Режим «Найди тройку».
- Три уровня сложности.
- Таймер и счётчик ходов.
- Экран победы.
- Перезапуск игры.
- Стиль Royal Purple.

## Установка

Установи Python 3.10 или новее.

Установи зависимости:

```bash
pip install -r requirements.txt
```

Запусти игру:

```bash
python main.py
```

## Сложность

### Найди пару

| Уровень | Поле | Пар |
|---|---:|---:|
| Легко | 4×4 | 8 |
| Средне | 4×5 | 10 |
| Сложно | 4×6 | 12 |

### Найди тройку

| Уровень | Поле | Троек |
|---|---:|---:|
| Легко | 3×4 | 4 |
| Средне | 4×6 | 8 |
| Сложно | 5×6 | 10 |

## Управление

- Левая кнопка мыши — открыть карточку.
- ESC — вернуться в меню.
- ENTER — начать новую игру после победы.
